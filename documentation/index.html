Overview

RankedBay is a marketplace template with a React/Vite frontend and Supabase-powered authentication and data layer. It is designed to be rebranded and connected to the buyer's own backend project.

Live demo: rankedbay.vercel.app
Important: the base product does not process online payments. The default purchase path sends the customer to WhatsApp.

Features

MarketplaceSearch, game filters, availability, featured listings and account details.
Account pagesImages, rank, level, skins, region, features and descriptions.
WhatsApp flowDirect enquiry/purchase contact from listing pages.
AuthenticationSupabase email/password signup, login and persistent sessions.
Admin dashboardManage listings, availability, featured status and enquiries.
Responsive UIDesktop, tablet and mobile layouts.
RLSDatabase access is protected with Supabase Row Level Security.
Central configCore branding and contact details live in one file.

Installation

  1. Extract the source package.
  2. Open a terminal in the project directory.
  3. Run npm install.
  4. Create a .env file with the Supabase variables.
  5. Configure the database using supabase/.
  6. Run npm run dev.
VITE_SUPABASE_URL=your-supabase-project-url
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
Security: never expose a Supabase service-role key in browser code or a distributed frontend package.

Supabase Setup

Create a new Supabase project and apply the supplied schema/seed files.

UPDATE profiles
SET role = 'admin'
WHERE username = 'your_username';

Sign out and sign back in after changing the role.

Configuration

Edit src/config/site.ts for brand name, tagline, WhatsApp number, email, social links and currency settings.

Before launch: replace placeholder contacts and demonstration content.

Admin Setup

Registration creates a customer by default. Promote your own account through Supabase rather than hard-coding privileged access in the frontend.

Database

profiles

Stores user identity and roles.

accounts

Stores listings including game, price, rank, level, skins, region, features, images and availability.

inquiries

Stores customer enquiries linked to listings and tracks their status.

Deployment

Deploy to Vercel or another platform that serves the built Vite application. Add the Supabase environment variables, deploy, then test authentication, listings, images and enquiry flows.

The included vercel.json provides the SPA rewrite needed for client-side routes.

Payments

The base template intentionally uses WhatsApp for purchase enquiries. It does not include a payment gateway. Paystack or Stripe can be integrated separately with appropriate server-side verification and webhooks.

Troubleshooting

Blank pageCheck the browser console, build output and SPA rewrite.
Authentication failsCheck Supabase variables and authentication configuration.
Listings missingVerify schema, seed data and RLS policies.
Wrong WhatsApp numberUpdate whatsappNumber in src/config/site.ts.
